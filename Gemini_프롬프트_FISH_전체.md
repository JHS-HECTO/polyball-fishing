## 작업 순서 권장
1. 황금 물고기 (14번) — 가장 중요. 톤 검증.
2. 잡어/일반/희귀/대물 (3~13번) — 통일감 위해 일괄.
3. 캐릭터 (2번).
4. UI 자산 (15, 16, 17, 18번).
5. 타이틀 배경 (1번) — 선택. CSS 그라데이션으로 대체 가능.

## 종횡비 가이드
- **세로 풀스크린 배경 (1번):** 9:19.5 또는 9:16 — 휴대폰 480px max-width 프레임 가득
- **세로 캐릭터 스프라이트 (2번):** 3:4 — angler.png 처럼 사람/캐릭터 세로
- **정사각 스프라이트 (3~14, 16, 17, 18번):** 1:1 — 물고기, 찌, 파티클. 게임 화면에 자유 배치
- **가로 티켓 (15번):** 4:3 — 실제 응모권 비율

## 후처리
- 배경 투명화: Gemini가 흰 배경 남기면 `scripts/remove-bg.py` 등으로 후처리.
- 사이즈: 위 명시 사이즈 → 사용처 맞게 리사이즈 (`public/images/...`).
